# Accessibility

This site is the accessible version of Natalie's CV.

- Text is left-aligned, with no justified blocks and no italics.
- Body text is set at a comfortable size and line height, with a maximum line length of about 68 characters.
- Colours meet WCAG 2.2 AA contrast requirements: body text is 16.5:1 against the page background, and headings are 12.5:1.
- The site can be zoomed and reflowed, and it prints to a plain, readable page.
- The PDF is a tagged PDF (PDF/UA-1), with real headings and reading order, so it works with screen readers.
